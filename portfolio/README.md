# Sanskar Pandey — One Piece themed 3D Portfolio

## Files
- `index.html`, `style.css`, `app.js`, `scene.js`, `fx.js`: the website (`fx.js` = click sparkle burst + manga speed lines)
- `config.js`: **edit your social links, GitHub repo links and optional photo here** (one place updates the whole site)
- `assets/Sanskar_Pandey_Resume.pdf`: updated resume (includes MCA, Cloud Computing, Parul University)
- `assets/three.min.js` + `assets/fonts/`: self-hosted, so no CDN is needed

## Add your photo (optional)
Save it as `assets/profile.jpg`, then set `photo: "assets/profile.jpg"` in `config.js`.

## Go live for free (pick one)
**GitHub Pages:** create a repo named `<your-username>.github.io`, upload the contents of this folder, and it goes live at `https://<your-username>.github.io`.
**Netlify:** drag and drop this folder at https://app.netlify.com/drop.
**Vercel:** `npx vercel` inside this folder.

## Run locally
`python -m http.server 8080` → open http://localhost:8080
